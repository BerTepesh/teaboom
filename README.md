# Тестовое задание — Карточка товара Teaboom.ru

Вёрстка верхней части карточки товара "Ананасовый улун" с интерактивным выбором фасовки, автообновлением артикула и цен, а также галереей Fancybox.

## Инструкция по запуску

Для корректной работы сборки Gulp на актуальных версиях Node.js (v17+) используется флаг поддержки устаревших алгоритмов OpenSSL.

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сборщика и режима отслеживания (Watch)
В первом терминале запустите Gulp-ворчер, который скомпилирует проект в папку `public`:
* **Для PowerShell:**
  ```powershell
  $env:NODE_OPTIONS="--openssl-legacy-provider"; npm run start
  ```
* **Для CMD:**
  ```cmd
  set NODE_OPTIONS=--openssl-legacy-provider && npm run start
  ```

### 3. Запуск локального сервера
Так как утилита BrowserSync может конфликтовать с сетевым окружением Windows (EADDRNOTAVAIL), локальный сервер для просмотра результатов запускается независимо во втором окне терминала через `live-server`:
```bash
npx live-server public --host=localhost --port=8085
```
После этого проект автоматически откроется в браузере по адресу: `http://localhost:8085/`.
